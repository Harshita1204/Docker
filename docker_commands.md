# Docker Commands

## Check Docker Version

```bash
docker --version
```

Meaning:
Shows the installed Docker version.

---

# Download Docker Image

```bash
docker pull nginx
```

Meaning:
Downloads the nginx image from Docker Hub.

---
# Show Downloaded Images

```bash
docker images
```

Meaning:
Displays all Docker images available on your system.

---

# Run a Container

```bash
docker run nginx
```

Meaning:
Creates and starts a container using the nginx image.

---

# Run Container in Background

```bash
docker run -d nginx
```

Meaning:
Runs the container in detached mode (background).

---

# Run Container with Port Mapping

```bash
docker run -p 8080:80 nginx
```

Meaning:
Maps:
- Host port `8080`
- Container port `80`

Open:

```txt
http://localhost:8080
```

to access nginx in browser.

---

# Give Name to Container

```bash
docker run --name mynginx nginx
```

Meaning:
Creates a container with custom name `mynginx`.

---

# Show Running Containers

```bash
docker ps
```

Meaning:
Shows only running containers.

---

# Show All Containers

```bash
docker ps -a
```

Meaning:
Shows:
- running containers
- stopped containers

---

# Stop a Container

```bash
docker stop mynginx
```

Meaning:
Stops the running container.

---

# Start a Container

```bash
docker start mynginx
```

Meaning:
Starts an existing stopped container.

---

# Restart a Container

```bash
docker restart mynginx
```

Meaning:
Stops and starts the container again.

---

# Remove a Container

```bash
docker rm mynginx
```

Meaning:
Deletes the container.

Note:
Container must be stopped before removing.

---

# Remove Docker Image

```bash
docker rmi nginx
```

Meaning:
Deletes the Docker image.

---

# Access Container Terminal

```bash
docker exec -it mynginx bash
```

Meaning:
Opens terminal inside the container.

Explanation:
- `exec` → execute command
- `-it` → interactive terminal
- `bash` → open bash shell

---

# Show Container Logs

```bash
docker logs mynginx
```

Meaning:
Displays logs generated by the container.

Useful for:
- debugging
- checking errors

---

# Show Live Container Resource Usage

```bash
docker stats
```

Meaning:
Shows:
- CPU usage
- memory usage
- network usage

for running containers.

---

# Copy File From Container to Host

```bash
docker cp mynginx:/usr/share/nginx/html/index.html .
```

Meaning:
Copies file from container to current folder.

---

# Copy File From Host to Container

```bash
docker cp index.html mynginx:/usr/share/nginx/html/
```

Meaning:
Copies local file into container.

---

# Remove All Stopped Containers

```bash
docker container prune
```

Meaning:
Deletes all stopped containers.

---

# Remove Unused Images

```bash
docker image prune
```

Meaning:
Deletes unused Docker images.

---

# Stop All Running Containers

```bash
docker stop $(docker ps -q)
```

Meaning:
Stops every running container.

---

# Remove All Containers

```bash
docker rm $(docker ps -aq)
```

Meaning:
Deletes all containers.

---

# Docker System Information

```bash
docker info
```

Meaning:
Shows detailed Docker system information.

---

# Search Images on Docker Hub

```bash
docker search ubuntu
```

Meaning:
Searches Docker Hub for ubuntu images.

---

# Build Docker Image

```bash
docker build -t myapp .
```

Meaning:
Builds Docker image from Dockerfile.

Explanation:
- `-t` → tag/name image
- `.` → current folder

---

# Run Container with Interactive Terminal

```bash
docker run -it ubuntu
```

Meaning:
Starts ubuntu container with terminal access.

---

# Exit Container

```bash
exit
```

Meaning:
Exits from container terminal.

---

- store Docker images
- download images
- share images

Website:

```txt
https://hub.docker.com
```
